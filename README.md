# microSOFT

Небольшие утилиты для администрирования Windows и сетевых ресурсов.

## Анализ сетевых папок

[NetworkFolderAudit](NetworkFolderAudit) — приложение для Windows 10/11 на Python 3.10+ без сторонних зависимостей.

- Подсчёт размеров каждой папки со всеми вложениями.
- Даты последнего обращения и изменения файлов во всём поддереве.
- По запросу — текущие владельцы папок и наиболее недавно изменённых файлов.
- Сортировка, остановка сканирования и экспорт CSV для Excel.
- Журнал отказов в доступе и пропущенных ссылок; неполные результаты явно помечаются.

### Запуск

Скачайте исходники (Code → Download ZIP), распакуйте архив, откройте папку `NetworkFolderAudit` и запустите `Start.bat`. Нужен Python 3.10+ с Tcl/Tk. Введите путь вида `\\\\server\\share` или `Z:\\` и нажмите «Сканировать».

Сохраняйте отчёты вне сканируемой папки. Подробности: [README_RU.txt](NetworkFolderAudit/README_RU.txt).

### Ограничения

Владелец ACL не обязательно создатель или последний загрузивший. Для точной атрибуции требуются сохранённые журналы аудита файлового сервера. Дата обращения зависит от настроек сервера и может быть неточной. Дата изменения файла не равна дате загрузки.

Считается логический размер, а не занятые блоки на сервере. Родительская строка уже включает дочерние. Ссылки, junction и прочие reparse points пропускаются.

### Проверки

```console
python -m unittest discover -s NetworkFolderAudit -v
```

Пять тестов проходят в Linux: вложенные размеры и даты, CSV, отказ в доступе, пропуск ссылок и отмена. Интерфейс и Windows API владельцев ещё требуют проверки в Windows с реальным SMB-ресурсом.
