# microSOFT

Небольшие утилиты для администрирования Windows и сетевых ресурсов.

## Анализ сетевых папок

[NetworkFolderAudit](NetworkFolderAudit) — приложение для Windows 10/11 на Python 3.10+ без сторонних зависимостей.

- Подсчёт размеров каждой папки со всеми вложениями.
- Даты последнего обращения и изменения файлов во всём поддереве.
- По запросу — текущие владельцы папок и наиболее недавно изменённых файлов.
- Фильтр по давности обращения: менее недели, неделя–месяц, 1–3, 3–6, 6–9, 9–12 и от 12 месяцев.
- Отдельные группы для отсутствующих дат, будущих дат и неполных данных.
- Размеры в ГБ (1 ГБ = 1 000 000 000 байт).
- Сортировка, остановка сканирования и экспорт выбранной группы в CSV для Excel.
- Журнал отказов в доступе и пропущенных ссылок; неполные результаты явно помечаются.

### Запуск без установки Python

Откройте [Actions → Windows portable EXE](https://github.com/neofart-art/microSOFT/actions/workflows/windows-portable.yml), выберите последнюю успешную сборку и скачайте артефакт **NetworkFolderAudit-Windows-x64**. Для скачивания артефакта требуется вход в GitHub.

Распакуйте ZIP и запустите **NetworkFolderAudit.exe**. Установка программы и Python не нужны. Сборка предназначена для Windows 10/11 x64.

Сборка проверяет запуск упакованного EXE без Python в PATH: окно, подсчёт файлов, экспорт CSV и получение владельца через Windows API. Это проверка на локальных тестовых данных Windows; совместимость с вашим SMB-сервером проверяется отдельно.

### Запуск из исходников

Скачайте исходники (Code → Download ZIP), распакуйте архив, откройте папку `NetworkFolderAudit` и запустите `Start.bat`. Нужен Python 3.10+ с Tcl/Tk. Введите путь вида `\\\\server\\share` или `Z:\\` и нажмите «Сканировать».

Сохраняйте отчёты вне сканируемой папки. Подробности: [README_RU.txt](NetworkFolderAudit/README_RU.txt).

### Ограничения

Владелец ACL не обязательно создатель или последний загрузивший. Для точной атрибуции требуются сохранённые журналы аудита файлового сервера. Дата обращения зависит от настроек сервера и может быть неточной. Дата изменения файла не равна дате загрузки.

Считается логический размер, а не занятые блоки на сервере. Родительская строка уже включает дочерние. Ссылки, junction и прочие reparse points пропускаются.

### Проверки

```console
python -m unittest discover -s NetworkFolderAudit -v
```

Девять тестов проходят в Linux: вложенные размеры и даты, CSV, отказ в доступе, пропуск ссылок и отмена, границы периодов, календарные месяцы и экспорт выбранной группы. Работа с реальным SMB-ресурсом требует проверки в вашей сети.

Давность оценивается по самому позднему обращению к файлам во всём поддереве, на момент завершения сканирования. Неделя — 7 дней; месяцы — календарные. Точная граница включается в более старую группу. CSV сохраняет группу и дату оценки; для полного отчёта выберите «Все папки». Журнал ошибок всегда включает всё сканирование.
