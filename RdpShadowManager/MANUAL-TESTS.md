# Ручная проверка на Windows

Следующие сценарии в исходной Linux-среде **не проверены**. Выполнять на разрешённых тестовых компьютерах, фиксируя версию Windows, язык, масштаб и результат.

- Windows 10/11 x64: запуск распакованной сборки на машине без .NET и Python.
- Получение сеансов по имени, FQDN, IPv4 и IPv6; русская и английская Windows.
- Несколько пользователей, активные и отключённые сеансы; отсутствие пользователей и исключение служебных записей / ID 0.
- Оба режима mstsc: согласие по умолчанию; без согласия при разрешающей и запрещающей политике. Главное окно остаётся открытым.
- Отказ в доступе, неверное имя DNS, выключенный ПК, недоступный RPC, заблокированный ICMP при доступном WTS.
- Недоступность отдельного WTS-поля: доступные данные сохраняются, ошибка есть в диагностике.
- Смена адреса во время запроса: очистка списка, завершение worker, отсутствие старых результатов. Повторные нажатия не создают параллельных worker.
- Тайм-аут 3 секунды для недоступного ПК: окно отзывчиво, worker завершён, следующий запрос возможен. Закрытие окна во время запроса не оставляет worker.
- Завершение/отключение сеанса или переиспользование ID другим пользователем перед нажатием «Подключиться»: запуск блокируется, нужен новый выбор.
- Отсутствующий mstsc и отказ запуска: понятная ошибка, системные подробности в диагностике.
- UAC: отдельная группа и статус обычных/повышенных прав; кнопка отключена при повышенных правах. При подтверждении сохраняются адрес и оба варианта режима согласия, сеансы загружаются заново без старого выбора. При отмене сохраняется исходное окно. Проверить отдельно, что локальное повышение не заменяет удалённые права.
- Масштаб 100/125/150/200%, перенос между мониторами: видимость и доступность элементов; раскрытие и копирование диагностики, работа клавиатурой.

Автоматическая Windows smoke-проверка проверяет только локальный WTS-процесс, не удалённый Shadow и не GUI.

## Удалённое обслуживание AutoDiscover — не проверено на реальных ПК

- Администратор и пользователь с разными SID: меняется только HKU SID выбранного пользователя; HKCU администратора/SYSTEM и локальный ПК не изменяются.
- Несколько активных пользователей: явная цель в диалоге, проверка SID при переиспользовании ID, остановка при выгруженном профиле.
- WinRM выключен/недоступен, отказ endpoint или удалённых административных прав: нет локального fallback, ненулевой результат и подробный отчёт.
- Office MSI 14/15/16, ClickToRun с Outlook и без него; нет Outlook — ни одной версии по умолчанию и явный выбор до записи.
- Исходные значения разных типов, отсутствующие значения, обе ветки и представления: полный снимок до записи, точное восстановление, сохранение самих ключей.
- Изменение значения сторонним приложением до/после preview: конфликт показан, принудительного перезаписывания нет. Повторная правка после успешного восстановления также конфликтует.
- Ошибка/обрыв сети между записью и подтверждением: результат не объявлен успешным, копия и журнал пригодны для последующего восстановления.
- Отсутствие доступа к каталогу резервных копий или небезопасный ACL: записи не начинаются.
- Закрытие Outlook выключено по умолчанию; включение требует предупреждения. Завершается Outlook только с совпадающими SID и ID сеанса; другие пользователи и сеансы не затронуты. Ошибки завершения отражаются в отчёте.
- Двойное нажатие, параллельный клиент и закрытие окна во время обслуживания: нет параллельной записи, интерфейс отзывчив, результат и путь копии видны.

Автотесты используют только одноразовый ключ HKCU `Software\RdpShadowManager-Tests-<GUID>` на GitHub runner и удаляют его после проверки. Это тест механизма сохранения типов, а не запуск профиля AutoDiscover на локальном компьютере администратора.

## Картинка и иконка

- Реальный масштаб Windows 100/125/150/200% и переход между мониторами: полная картинка не искажается, не перекрывает кнопки и таблицу; её колонка добавлена к прежней ширине окна.
- Маленькая/большая иконки EXE в Проводнике, главного окна, Alt-Tab и панели задач; читаемость лица на 16/24/32 px.
- Перенести только portable EXE/README на чистую машину: JPG/ICO рядом не требуются.

CI выполняет программную симуляцию масштаба и сохраняет изображения разметки; реальные системные DPI и панель задач в интерактивном Windows-сеансе пока не проверены.
